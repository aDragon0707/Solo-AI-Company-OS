
## How AI Should Use This Matrix

At the start of a task:

1. Read the relevant founder-approved decision or task brief.
2. Read the relevant dashboard or project state.
3. Read your role file.
4. Read this matrix.
5. Use only skills assigned to your working identity unless the founder or AI-01 explicitly routes the task differently.

At the end of a task:

1. State which skill was used.
2. State whether the skill worked.
3. Write or update a worklog when state changed.
4. Recommend a new skill only if the worklog contains a repeatable pattern.

---

## Boundary

If a skill conflicts with the founder's latest explicit decision, the founder decision wins.

If a skill conflicts with verified project truth, verified project truth wins.

If a skill would make the AI sound more certain than the files allow, do not use it.

For broad documentation governance, use `00_System_Brain/Doc_Memory_Spine_Skill.md`.
