# Skill Memory Layer

**Purpose:** Turn useful AI work into reusable company ability.

This folder is where successful collaboration patterns become skills that future AI windows can reuse.

The loop is:

```text
Founder decision -> AI execution -> worklog -> skill -> better future execution
```

Skills do not replace founder decisions. They help AI employees remember proven ways of working.

---

## What A Skill Is

A skill is a reusable working pattern.

It should explain:

- when to use it
- which AI employee can use it
- what files to read first
- what steps to follow
- what not to assume
- how to report the result

An AI employee is not a person. It is a reusable working identity with context, responsibilities, and assigned skills.

---

## Core Files

- `SKILL_LIBRARY.md` lists the starter skills.
- `SKILL_TEMPLATE.md` is the format for adding a new skill.
- `AGENT_SKILL_MATRIX.md` maps AI employees to the skills they can use.
- `WORKLOG_TO_SKILL_PROMPT.md` helps AI convert a completed worklog into a reusable skill.

---

## How To Use This Layer

1. Complete a real work session.
2. Write a worklog.
3. Ask AI-01 or the relevant AI employee whether the worklog contains a reusable pattern.
4. If yes, use `WORKLOG_TO_SKILL_PROMPT.md`.
5. Add the new skill to `SKILL_LIBRARY.md`.
6. Assign it in `AGENT_SKILL_MATRIX.md`.

Do not create skills from wishes, ideas, or vague chat summaries. A skill should come from completed or clearly tested work.

---

## Authority Rule

Skills are downstream of founder decisions.

Use this order when files conflict:

1. founder decision log
2. verified project truth
3. current dashboard state
4. AI worklogs
5. skills
6. older drafts or chat history

A skill may improve execution. It must not create authority.
