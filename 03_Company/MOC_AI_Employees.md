## Daily Use

1. Open `AI_Employees/AI_EMPLOYEE_COMMAND_CENTER.md`.
2. Pick the correct AI employee.
3. Copy the employee's `START_PROMPT.md`.
4. Add the current task.
5. Require a worklog or handoff before the task is closed.

Default collaboration is `AI-01 + AI-02 + AI-04 + Human`. Use the five-role model only for complex work that needs building, review, public expression, and learning/memory.
