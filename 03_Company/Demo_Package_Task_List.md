## 2. Demo Rules

Demo assets may:

- describe the product category
- show sanitized examples
- explain the workflow
- state limitations

Demo assets must not:

- reveal sensitive source materials
- name private customers without permission
- imply unsupported certainty
- expose implementation details that do not belong in customer materials

## 3. Review Gate

Before external use:

1. AI-03 checks clarity and customer relevance.
2. AI-04 checks claim boundaries.
3. AI-02 checks technical or source-truth references.
4. Founder approves final sending.
