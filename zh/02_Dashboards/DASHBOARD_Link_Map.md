## 链接维护规则

- 内部 vault 导航优先使用 Obsidian wiki-link：`[[folder/file|可读标签]]`。
- 必要时保持面向 GitHub 的文档使用常规路径以便阅读。
- 每个重要笔记应至少链接到一个父级地图、仪表盘或分类账。
- 不得添加暗示笔记中不存在的决策、事实或依赖关系的链接。
- 链接时不得改写实质内容。链接是导航工作，而非战略工作。
- 仪表盘、MOC、工作日志索引或交接的维护请遵循 [[../../00_System_Brain/AI_Text_Maintenance_Protocol|AI 文本维护协议]]。
