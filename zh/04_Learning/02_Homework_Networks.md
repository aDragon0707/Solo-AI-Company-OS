# 作业 02 - 外部输入与网络

**目的:** 理解信息如何从外部进入系统。

---

## 1. 创始人级概念

外部输入不是中性的。它们可能不完整、延迟、不一致或错误。

系统必须知道：

```text
这些信息来自哪里？
它携带了什么上下文？
我们能验证它吗？
我们不应该从中推断什么？
```

---

## 2. 必做练习

画一个简单的输入路径：

```text
[外部来源] -> [数据采集组件] -> [完整性验证] -> [分析输出]
```

然后回答：

```text
什么进入了系统？
需要什么上下文？
什么可能出错？
什么必须被记录？
如果输入不完整，不应该断言什么？
```

---

## 3. 达标标准

当你能够解释为什么系统必须记录输入上下文而不仅仅是记录最终输出时，你就合格了。
