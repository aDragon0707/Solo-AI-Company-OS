# 从这里开始 - 零代码创始人

**目的:** 开始学习系统，而不陷入实现细节的泥潭。

---

## 1. 代码不是起点

不要从逐行阅读代码开始。

先问自己：

```text
这个部分为什么存在？
它在整个系统中承担什么职责？
如果它撒谎、猜测或消失了，什么会出问题？
```

只有回答完这些问题后，才应该去了解代码是如何工作的。

---

## 2. 创始人阅读顺序

对于任何 module，按以下顺序阅读：

1. 意图：它为什么存在。
2. 拓扑：它位于何处。
3. 输入：它接收什么。
4. 输出：它产生什么。
5. 风险：它必须保护什么。
6. 代码：关键路径如何工作。

---

## 3. 基础术语

`module`

系统中承担特定职责的部分。

`input`

module 接收的内容。

`output`

module 返回、写入或更改的内容。

`critical path`

系统要变得可信赖，必须正常工作的少数几个步骤。

`boundary`

module 或 AI 员工不得越过的界限。

---

## 4. 第一个任务

在"我的AI协作操作系统"中挑选一个 module 或文件。

写下：

```text
这个模块的存在是因为：
它位于……之后：
它位于……之前：
它的输入是：
它的输出是：
它绝不能：
```

这些就是第 1 天需要完成的量。
