# 作业 01 - 数据结构

**目的:** 理解数据结构就是公司命名和传递信息的方式。

---

## 1. 创始人级概念

数据结构不仅仅是代码。

它是一种约定，表明：

```text
这是系统所需的信息。
这是每个字段的含义。
这是绝不能猜测的内容。
```

---

## 2. 必做练习

在"我的AI协作操作系统"中选择一个结构化对象。

回答：

```text
它代表了什么现实世界概念？
哪些字段是必需的？
哪些字段可能是未知的？
如果某个字段缺失应该怎么办？
如果这个结构出错，哪些主张会变得不可靠？
```

---

## 3. 练习模板

```markdown
## 数据结构审查

名称：
架构意图：
所处位置：
输入：
输出：
我理解的字段：
我不理解的字段：
出错时的风险：
```

---

## 4. 达标标准

当你能够用业务语言而不是语法来解释这个结构时，你就合格了。
