## 2. 每条 AI 窗口的守则

每次启动 AI，必须先阅读：

1. 创始人决策日志
2. 相关 dashboard
3. 自身的角色文件
4. 协作协议
5. worklog 索引

每次结束 AI 会话时，必须撰写 worklog，或明确说明为何不需要写 worklog。
