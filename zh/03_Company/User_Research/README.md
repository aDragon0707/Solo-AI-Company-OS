# 用户研究

**目的：** 收集公开的痛点信号，将其转化为更好的 onboarding、定位、示例和产品决策。

此目录用于市场和用户关于人机协作的研究。不得用于复制私密用户数据或粘贴完整对话。

## 研究守则

利用公开讨论来理解用户的表达方式、痛点和流程摩擦。

请勿：

- 复制私密消息
- 包含真实姓名，除非来源是明确公开且有必要注明出处
- 粘贴大量受版权保护的内容
- 将点赞数当作事实证据
- 将一条激烈评论直接变成产品决策

所有面向产品的改动仍需创始人判断。

---

## 最佳信号

高质量的研究信号通常描述：

- 反复出现的工作流故障
- 人们已经在使用的变通方案
- 人们自然而然用来描述该问题的表达
- AI 工作变得难以管理的节点
- 独立创业者感到力不从心的时刻

弱信号包括：模糊的兴奋感、毫无讨论的发布帖、或只说某个工具很酷的评论。
