## 使用守则

演示材料必须满足：

- 通用化或经过适当的脱敏处理
- 明确界定范围
- 如实说明不确定性
- 发送前获得批准

演示材料不得包含：

- 敏感原始资料
- 私密的客户信息
- 不面向客户的实现细节
- 无依据的宣称
