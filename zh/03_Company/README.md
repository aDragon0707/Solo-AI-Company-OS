# 公司工作区

**目的：** 管理公司运营、AI 员工、面向客户的资产、客户账户和工作日志，避免与创始人决策记录或项目事实来源混在一起。

**创始人首先阅读：** `../../FOUNDER_START_HERE.md`

---

## 1. 哪些内容属于这里

本工作区用于：

- 公司运营手册
- 产品与服务定位
- 客户获取规划
- 报价与定价模型
- 演示资料包草稿
- 客户工作区
- AI 员工提示词与协调规则
- AI 工作日志

请勿将本文件夹用作已核实的项目事实来源。公司资料可以汇总已核实的事实，但不得覆盖它们。

```text

```

---

## 4. 默认运营循环

1. 创始人审查 `01_Founder/FOUNDER_Decision_Log.md`。
2. AI-01 检查仪表盘和工作日志。
3. AI-01 将工作分配给相应的 AI 员工。
4. 被分配的 AI 完成任务并撰写工作日志。
5. 任何跨角色的任务都包含交接部分。
6. 创始人确认决策、客户承诺和对外声明。
