# Solo-AI-Company-OS 中文指南

**一句话：** 这是一套用 Markdown / Obsidian 管理人-AI 协作的操作系统。

它不是 prompt 合集，也不是普通的第二大脑模板。它解决的是：

```text
AI 工作散落在聊天记录里，决策、进度、上下文和交接都留不下来。
```

核心原则：

```text
人做决策。AI 做执行。Markdown 留记忆。Worklog 做交接。
```

## 这套系统适合谁

适合：

- 高频使用 AI 的 solo founder
- 用 Codex / Cursor / Claude Code 做项目的人
- 需要多个 AI 窗口协作的人
- 希望 AI 工作留下记录、交接和状态的人
- 想用 Obsidian 管理 AI 工作记忆的人

不适合：

- 想要全自动 agent 平台的人
- 只想收藏一堆 prompt 的人
- 不想写任何记录的人
- 只需要漂亮笔记主题的人

## 中文文档怎么用

中文文档帮你理解流程：

```text
下载 -> 安装 -> 打开 Obsidian -> 读 FIRST_30_MINUTES.md -> 运行第一轮 AI-01
```

真正要复制给 AI 的正式 prompt，仍然使用英文 Core 里的文件。

你可以在复制英文 prompt 后追加一句：

```text
Please reply in Chinese.
```

或者：

```text
请用中文回复我，但继续遵守上面的英文系统规则。
```

---

## 最重要的四个概念

```text
Founder Decision Log = 人类正式决策
AI Employee = 有职责边界的 AI 角色
Worklog = AI 工作后留下的交接记录
Dashboard = 当前状态摘要
```

如果你只记住一句话：

```text
不要让 AI 工作只留在聊天窗口里。
```
