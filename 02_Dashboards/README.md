# Dashboards

**Purpose:** Keep the current operating state visible without replacing founder decisions or worklogs.

Dashboards are summaries. They help the founder and AI employees orient quickly, but they are not the source of truth.

---

## Dashboard Files

- `DASHBOARD_Company_State.md` - current priorities, blockers, decisions needed, and next owners

---

## Authority Rule

If the dashboard conflicts with the founder decision log, the founder decision log wins.

If the dashboard conflicts with a worklog, check the worklog and update the dashboard.

If a fact is not verified, mark it as `not yet verified` instead of making it look complete.

---

## Update Rhythm

AI-01 should review this folder during coordination work.

Update the company state dashboard when:

- a priority changes
- a blocker appears or clears
- a founder decision is needed
- an AI employee completes meaningful work
- ownership of the next step changes
