# First 7 Days

**Purpose:** A one-week learning path for a founder who wants system understanding without drowning in code.

---

## Day 1 - Map Before Code

Read:

- `00_Start_Here_Zero_Code.md`
- `00_Project_Map_For_Founder.md`

Do:

```text
Pick one module. Write why it exists and where it fits.
```

---

## Day 2 - Data Structures As Company Language

Read:

- `00_Glossary_Zero_Code.md`
- `01_Homework_Data_Structures.md`

Do:

```text
Identify one object, list, or dictionary in [Project Name].
Explain what company concept it represents.
```

---

## Day 3 - Inputs And Outputs

Do:

```text
Choose one function or workflow.
Write its input, output, and what must be true before it runs.
```

---

## Day 4 - External Systems

Read:

- `02_Homework_Networks.md`

Do:

```text
Draw how information enters the system from outside.
```

---

## Day 5 - Integrity And Storage

Read:

- `03_Homework_Computer_Organization.md`

Do:

```text
Explain why source material must remain reviewable.
```

---

## Day 6 - Concurrency And Order

Read:

- `04_Homework_Operating_Systems.md`

Do:

```text
Explain why the system should control parallel work instead of doing everything at once.
```

---

## Day 7 - AI Boundaries

Read:

- `05_Homework_AI_Systems.md`

Do:

```text
Explain why AI should preserve uncertainty instead of filling every blank.
```

---

## End Of Week Standard

The founder should be able to say:

```text
I understand the main topology of [Project Name].
I can describe why a module exists before asking how the code works.
I know which claims need verification before they can be used.
```
