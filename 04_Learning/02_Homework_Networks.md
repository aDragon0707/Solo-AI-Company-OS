# Homework 02 - External Inputs And Networks

**Purpose:** Understand how information enters the system from outside.

---

## 1. Founder-Level Concept

External inputs are not neutral. They can be incomplete, delayed, inconsistent, or wrong.

The system must know:

```text
Where did this information come from?
What context came with it?
Can we verify it?
What should we not infer from it?
```

---

## 2. Required Exercise

Draw a simple input path:

```text
[External Source] -> [Data Capture Component] -> [Integrity Verification] -> [Analytical Output]
```

Then answer:

```text
What enters the system?
What context is needed?
What can fail?
What must be recorded?
What should not be claimed if the input is incomplete?
```

---

## 3. Passing Standard

You pass when you can explain why the system must record input context instead of only recording final outputs.
