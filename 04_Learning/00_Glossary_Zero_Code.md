# Zero-Code Glossary

**Purpose:** Short definitions for founder-level technical literacy.

---

## System Terms

`topology`

The map of how major parts connect.

`module`

A focused part of the system with a defined responsibility.

`contract`

An agreement about what data or behavior a module expects.

`critical path`

The smallest path that must work for the system to deliver value.

`source truth`

The verified material that claims must trace back to.

---

## Code Terms

`variable`

A named container for a value.

`function`

A small machine that receives input and returns output.

`class`

A template for a structured object or role.

`list`

An ordered collection of items.

`dictionary`

A set of key-value pairs.

`null`

Unknown or empty. In a disciplined system, null is better than guessing.

---

## Operating Terms

`verification`

A check that something is true, complete, or preserved.

`handoff`

The context passed from one AI employee to another.

`worklog`

A durable record of what was done, what changed, and what remains.

`claim boundary`

The line between what can be said and what is unsupported.
